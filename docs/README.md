# Documentation & AI Working Notes

This directory contains the internal context, architecture notes, and design documents created during the development of Quaestio.

Because Quaestio was vibe-coded collaboratively with AI assistants (Claude Code and Google Antigravity), these working documents are intentionally preserved and kept public to document the real learning path of the project. Except for this file, all documents in this directory are written in Italian (the original working language).

## Subdirectories

- **`claude/`**: Core project context loaded by Claude Code at each development session. Contains architectural guidelines (`architettura-gui.md`), data model notes (`contenuti-e-dati.md`), platform setup and distribution instructions (`piattaforme-e-distribuzione.md`), project history and completed milestones (`storia-e-roadmap.md`), and the index of lessons learned and pitfalls avoided (`trappole.md`).
- **`superpowers/`**: Design specifications (`specs/`) and step-by-step implementation plans (`plans/`) drafted before executing each feature or architectural transition.
- **`images/`**: Screenshots and graphical assets used in the main repository documentation.
