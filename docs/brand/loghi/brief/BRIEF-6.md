## Il problema dei colori

Rosso + blu + ocra + verde insieme **ricordano troppo il marchio Google**. Da qui in poi i quattro colori si pescano
dalla **tavolozza estesa** di 16 inchiostri (toni medi, pieni ma smorzati), evitando la quaterna rosso/blu/giallo/verde:

| Nome | Hex | | Nome | Hex |
|---|---|---|---|---|
| Rosso | `#d6414b` | | Petrolio | `#308ea6` |
| Terracotta | `#e0703a` | | Azzurro | `#539fd4` |
| Cacao | `#8f5f3d` | | Blu | `#3a6cb8` |
| Ocra | `#ebaf00` | | Indaco | `#4d4dbc` |
| Oliva | `#95a63f` | | Viola | `#8559b0` |
| Prato | `#3fa66a` | | Prugna | `#a63f8c` |
| Verde acqua | `#40a79b` | | Rosa antico | `#d06a95` |
| Ardesia | `#5c6370` | | Grigio | `#d7d7d7` |

Ogni variante usa **una quaterna diversa**, scelta con criterio (scrivila nel testo con nomi ed hex), per esempio
toni caldi con un freddo di contrasto (terracotta, ocra, prugna, petrolio) oppure freddi con un caldo (indaco,
verde acqua, azzurro, terracotta). Restano le regole: almeno 4 colori, bianco/grigio/nero solo come spazio
negativo; Q dell'icona e parola nello stesso carattere; leggibile a 28 px.

## a5-5 · Corsie Beethoven → tre varianti (a6-1, a6-2, a6-3)

Il lettering a doppia corsia (corsia esterna neutra, corsia interna colorata) è **la cosa più apprezzata**: tieni
il carattere e sviluppalo. Correggi l'icona: la Q con le croci ricordava un **mirino** → togli le croci, la Q deve
essere la stessa lettera della parola. Tre variazioni sul tema (es. numero di corsie, quale corsia porta il colore,
colore per lettera o per pezzo di lettera, spessori).

## a5-4 · Mosaico stencil → tre varianti (a6-4, a6-5, a6-6)

Il mosaico di frammenti piace, ma l'utente chiede di **fare il mosaico con linee curve invece che dritte**: i tagli
che dividono le lettere in frammenti diventano archi (porzioni di cerchio), come nei poster di archi concentrici
(`ispira-3-cerchi.png`). Correggi anche la coda della Q, che a 45° ricordava una **lente di ricerca**. Lo stencil
resta un carattere disegnato da te, uguale nella Q e in tutte le lettere di "quaestio".
